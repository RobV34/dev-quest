Dev Quest

An interactive developer portfolio built as a side-scrolling game.

Instead of opening with a traditional portfolio page, Dev Quest lets visitors guide a developer character through a short career-themed quest. Each stage represents part of my professional toolkit before the visitor reaches the full portfolio.

The Quest

The game progresses through four stages:

Development — React, Node.js, Java and Spring Boot

Scrum / Agile — sprint planning, backlog work, daily Scrum and retrospectives

Project Management — planning, scope, coordination, risk and delivery

Data — PostgreSQL, data processing, analysis and insights

Completing the quest unlocks the portfolio, while visitors who prefer a traditional experience can use Skip to Portfolio at any time.

The game uses custom React state, keyboard and touch controls, platform collision, gravity/jumping, pickups, progression states and a side-scrolling camera.

Controls

Desktop

Move: Left / Right Arrow or A / D

Jump: Space

Mobile / Touch

On touch devices, on-screen Left, Jump, and Right controls are displayed automatically.

Run Locally

Clone the repository and install the dependencies:

git clone https://github.com/RobV34/dev-quest.git
cd dev-quest
npm install
npm run dev

Then open the local Vite address shown in the terminal.
